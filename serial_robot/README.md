# Serial Robot Implementation

This directory contains the KS-MP implementation for a UR10e serial
manipulator equipped with an RG2-FT gripper.

The implementation provides morphology-specific forward kinematics and
Jacobian evaluation while retaining the same discrete-time KS-MP control
structure used for the other robot morphologies in this repository.

## Files

### `pmp_serial.py`

Main serial-robot implementation, including:

- minimum-jerk goal-directed references;
- oscillatory references;
- VTGS references;
- peg-insertion references with planar oscillation;
- damped least-squares and Jacobian-transpose mappings;
- diagonal participation and damping matrices;
- explicit Euler integration;
- Jacobian-conditioning diagnostics;
- local discrete-time stability diagnostics;
- runtime measurement and CSV logging.

### `dh_fk.py`

Kinematic utilities, including:

- standard Denavit–Hartenberg forward kinematics;
- UR10 and UR10e geometric parameters;
- forward kinematics for the UR10e tool frame;
- the fixed transformation from the UR10e tool frame to the RG2-FT TCP;
- numerical translational Jacobians computed using central differences.

## Reproducibility scope

The scripts in this directory reproduce the algorithmic serial-robot
experiments and generate joint-space and task-space trajectories.

The provided implementation does not send commands directly to a physical
UR10e. Hardware communication, safety supervision, and low-level robot
execution should be implemented separately for a specific experimental setup.

All reported tracking deviations, Jacobian diagnostics, and local stability
metrics generated by this script are controller-internal, model-based
quantities rather than direct physical measurements.

## Requirements

- Python 3
- NumPy

Install the required Python package with:

```bash
pip install numpy
```

## Basic usage

Run the examples from this directory:

```bash
cd serial_robot
```

### Default goal-directed motion

The default command runs a minimum-jerk reference using the default initial
configuration, target, controller gains, and integration settings:

```bash
python pmp_serial.py
```

### Specify a Cartesian target

The target is defined as an end-effector position in millimetres:

```bash
python pmp_serial.py \
  --traj minjerk \
  --target -491.73 181.25 119.76
```

### Specify the initial joint configuration

Joint angles are given in degrees:

```bash
python pmp_serial.py \
  --traj minjerk \
  --q0 180 -85 -100 0 90 357.58 \
  --target -491.73 181.25 119.76
```

### Oscillatory reference

Run an oscillatory primitive with one cycle:

```bash
python pmp_serial.py \
  --traj osc \
  --osc-ay 55 \
  --osc-cycles 1 \
  --osc-lx 150
```

The oscillation parameters are:

- `--osc-ax`: oscillation amplitude along the first planar direction;
- `--osc-ay`: oscillation amplitude along the second planar direction;
- `--osc-cycles`: number of cycles during the primitive;
- `--osc-lx`: translational drift length for the drifted oscillation.

### Peg-insertion reference

Run a downward insertion reference with a small planar oscillation:

```bash
python pmp_serial.py \
  --traj peg \
  --target -491.73 181.25 60 \
  --peg-osc-amp 1.0 \
  --peg-osc-freq 1.0 \
  --peg-xy-mode x0
```

Available planar reference modes are:

- `x0`: retain the initial planar position;
- `target`: use the target planar position;
- `minjerk`: move smoothly from the initial planar position to the target.

This command generates the kinematic insertion reference only. Contact
forces, force-triggered stopping, and hardware safety logic are not included
in this standalone implementation.

## Differential mapping

### Damped least-squares mapping

Damped least squares is used by default:

```bash
python pmp_serial.py \
  --traj minjerk \
  --lam2 1e-4
```

The differential map is

```math
J_{\lambda}^{\dagger}
=
J^{T}
\left(
JJ^{T}+\lambda^{2}I
\right)^{-1}.
```

### Jacobian-transpose mapping

Use the Jacobian-transpose realisation with spectral scaling:

```bash
python pmp_serial.py \
  --traj minjerk \
  --use-jt \
  --jt-mu 2.0
```

The transpose update is locally scaled using the spectrum of the mapped
task-space operator.

## Participation matrix

The diagonal participation matrix can be specified using one value or six
joint-specific values.

Use full participation:

```bash
python pmp_serial.py \
  --c-vec 1
```

Reduce or remove the participation of selected joints:

```bash
python pmp_serial.py \
  --c-vec 1 1 1 0 1 1
```

A value of `1` represents full participation, while `0` removes the
corresponding joint contribution from the update.

## Damping

Task-space damping can be configured independently along the three Cartesian
axes:

```bash
python pmp_serial.py \
  --dp-x 0.2 \
  --dp-y 0.2 \
  --dp-z 0.2
```

Joint-side attenuation is specified using:

```bash
python pmp_serial.py \
  --bq-diag 0 0 0 0 0 0
```

## Default settings

| Parameter | Default value |
|---|---:|
| Differential mapping | Damped least squares |
| Reference type | Minimum jerk |
| Number of steps | 1500 |
| Integration timestep | 0.004 s |
| Primitive duration | 6 s |
| Isotropic task gain | 100 |
| Task damping | 0.2 per axis |
| DLS regularisation, \(\lambda^2\) | \(10^{-4}\) |
| Participation matrix | \(I_6\) |
| Joint-side attenuation | \(0_{6\times6}\) |
| TCP offset along tool-frame \(z\) | 233.6 mm |

The default initial joint configuration is:

```text
[180.0, -85.0, -100.0, 0.0, 90.0, 357.58] deg
```

The default Cartesian target is:

```text
[-491.73, 181.25, 119.76] mm
```

## Coordinate and unit conventions

- Cartesian positions are expressed in millimetres.
- Joint angles are expressed in degrees.
- Time is expressed in seconds.
- The translational Jacobian has units of millimetres per degree.
- Roll, pitch, and yaw are returned in degrees using a ZYX convention.
- The reported TCP includes the fixed RG2-FT tool offset defined in
  `dh_fk.py`.

## Outputs

Each run writes two files to the current working directory.

### `results_head.csv`

The complete experiment log, including:

- time;
- current Cartesian position;
- Cartesian reference;
- task-space virtual command;
- joint-rate update;
- joint configuration;
- task-space deviation;
- Jacobian singular values and condition number;
- local discrete-time spectral-radius diagnostic;
- Jacobian-transpose scaling values;
- total and component-level runtime measurements.

### `results.txt`

A compact legacy-compatible output containing:

```text
q1 q2 q3 q4 q5 q6 x y z
```

where the first six columns are joint angles and the final three columns are
the Cartesian TCP position.

## Terminal summary

After execution, the script prints a summary containing:

- mapping type;
- number of steps and integration timestep;
- target position;
- mean and 95th-percentile step time;
- RMS, mean, final, and maximum tracking deviation;
- maximum Jacobian condition number;
- maximum local spectral radius.

The printed timing values are wall-clock measurements of the Python
implementation and may vary across computers, operating systems, and runtime
conditions.

## Example reproduction command

The following command reproduces the default serial-robot configuration used
by the script:

```bash
python pmp_serial.py \
  --traj minjerk \
  --q0 180 -85 -100 0 90 357.58 \
  --target -491.73 181.25 119.76 \
  --steps 1500 \
  --dt 0.004 \
  --submv-T 6 \
  --kp1 100 \
  --dp-x 0.2 \
  --dp-y 0.2 \
  --dp-z 0.2 \
  --lam2 1e-4 \
  --bq-diag 0 0 0 0 0 0 \
  --c-vec 1 1 1 1 1 1
```
